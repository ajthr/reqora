# Reqora v0.1.0-beta.1

The first public beta of Reqora, a free, local REST API client for desktop and browser use.

## Included

- Shared React/TypeScript interface for Windows, macOS, Linux, and the web UI.
- Multiple local workspaces and named environments, scoped variables, duplication, and reviewed import/export.
- Collections, nested folders, ordering, folder exports, and folder-scoped runs.
- HTTP requests with JSON/XML/text, URL-encoded forms, multipart uploads, and binary bodies.
- Basic, bearer, API key, OAuth 1.0a, OAuth 2.0, Digest, and AWS Signature V4 authentication.
- Cookie jars, proxies, custom certificate authorities, and client certificates.
- Response search/navigation, JSON tree filtering, previews, saved examples, and response comparison.
- Custom/imported JSON schema validation, assertions, scripts, and response-to-variable extraction.
- Named local mock scenarios with delay, cancellation, failure simulation, and binary responses.
- Data-driven collection runs and a CLI with JSON/JUnit reports.
- Reqora, Postman, Insomnia, OpenAPI JSON, and common cURL imports.

## Downloads and installation

Choose your OS and CPU: `win32`, `linux`, or `darwin`; `x64` or `arm64`.

Each target provides three installation modes:

- **desktop**: Electron desktop app and request engine.
- **web**: Browser UI, local request engine, and bundled Node.js runtime.
- **both**: Both desktop and browser installations.

Windows: run the matching `*-setup.exe` wizard.

Linux/macOS: extract the matching `.tar.gz`, open its directory, and run `./install.sh`. Run as your normal user, without `sudo`. macOS ARM64 is for Apple Silicon; macOS x64 is for Intel Macs.

Node.js, npm, and Docker are not required on the destination machine. See [installation and upgrade instructions](https://github.com/ajthr/reqora/blob/v0.1.0-beta.1/docs/installation.md).

Verify installers with `SHA256SUMS.txt` or the platform-specific checksum files before installing. `release-manifest.json` records the tested source commit, workflow run, and hashes.

## Beta limitations

- These beta installers are **unsigned on Windows**. macOS apps are **ad-hoc signed and not notarized** unless a separate signing process is configured. Expect operating-system verification warnings; do not treat these builds as signed production distributions.
- Saved credentials, cookies, certificates, and variables are not encrypted. Exports can contain those values; keep them private.
- Save request edits before closing the application. Unsaved tabs are not restored after a restart.
- Exported attachments contain metadata, not file bytes. Reattach files when moving between devices or browser/desktop stores.
- Mocks execute within Reqora; they do not expose hosted mock endpoints.
- OpenAPI imports accept JSON, and schema/JSON-path support is intentionally limited to the documented subset.
- Native package smoke checks exercise installation, bundled runtimes, CLI/engine behavior, and uninstallation; they do not replace interactive UI and platform compatibility testing.

Back up saved workspaces before upgrading. Report reproducible issues at [GitHub Issues](https://github.com/ajthr/reqora/issues), without attaching credentials or unredacted workspace exports.
